# Test plan: Stage 5a idempotent payouts

## Scope

`services/api/src/modules/payouts` (state machine in `payouts.state.ts`, failure classification in `payouts.failure.ts`, `payouts.service.ts`, hourly `payouts.cron.ts`), the `payout_history` columns added by migration `0001_thin_iron_fist.sql`, and every reader of `payout_history` (admin, agency, freelancer services). Design: `docs/decisions/0005-payout-state-machine-and-idempotent-transfers.md`.

Use Stripe test keys and throwaway data only. Never use or print the real `.env`.

The real-Stripe scenarios in section 2 (idempotency replay, `transfer_group` listing, the `reversed` / `amount_reversed` fields, the 24 h key expiry, and the destination-change case) MUST be run with test-mode keys before this code is ever used with real money. The automated tests mock Stripe, so they prove the service's own logic and SQL, not Stripe's behavior.

## Deployment warning

NO intermediate state of this change is safe to run against an unmigrated dev database. The code selects and writes `status`, `attempts`, `claimed_at`, `next_retry_at`, `paid_at`, `notified_at`, `idempotency_key`, `last_error` and `destination_account_id`, and the readers filter on `status = 'PAID'`. Migration `0001` and the code must be deployed together. Sections 2 and 3 must only be run after the user has migrated the dev database. Automated tests run only against the `_test` database (already migrated with 0001).

Legend: U unit, I integration (real Postgres `_test`, Stripe mocked), E end to end / manual.

## Blocked on a decision

Fee, escrow and dispute rules are "to confirm" in `docs/product.md`. Payout amounts come from `earning_history` as integer cents (net = amount_cents - platform_fee_cents, ADR 0006); no scenario here validates the amount calculation, only its transfer.

## Known unverified at QA time

- Sections 2 and 3: no real Stripe keys were used and the dev database was deliberately not touched.
- The backfill `UPDATE` in `0001_thin_iron_fist.sql` was read, not executed against old data.
