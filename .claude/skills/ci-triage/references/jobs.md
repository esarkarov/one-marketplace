# CI jobs and the local equivalent

| Job                 | CI command                                                                                                | Local                                                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `check`             | `pnpm check`                                                                                              | `pnpm check` (format check fails on CRLF; use `pnpm exec prettier --check --end-of-line auto <files>`)                               |
| `build`             | `pnpm -r build`                                                                                           | `pnpm -r build`                                                                                                                      |
| `api-test`          | `db:test:migrate`, vitest with coverage and junit, `openapi:generate`, `git diff --exit-code` on the spec | `pnpm --filter @onemarketplace/api db:test:setup`, then `test:quiet`, `openapi:generate`, `git diff --stat -- docs/api/openapi.json` |
| `gitleaks`          | `gitleaks git --config .gitleaks.toml --redact -v --no-banner .`                                          | same                                                                                                                                 |
| `audit`             | `pnpm audit --prod --audit-level high`                                                                    | same (informational)                                                                                                                 |
| `dependency-review` | action, pull requests only                                                                                | not reproducible                                                                                                                     |
| `codeql`            | action, config `.github/codeql/codeql-config.yml`                                                         | not reproducible; read the alert                                                                                                     |
| `workflow-lint`     | actionlint 1.7.12                                                                                         | not installed locally                                                                                                                |
| `compose-validate`  | `docker compose -f infra/docker/docker-compose.yml config -q` with placeholder env                        | needs Docker and env vars set inline                                                                                                 |
| `ci-pass`           | aggregates the blocking jobs                                                                              | none                                                                                                                                 |
