# ADR format (taken from docs/decisions)

```
# 0025: Short decision title

Status: accepted. One sentence on scope and what is implemented.

## Context

What was found, with dates and file names.

## Decision

1. Numbered, testable statements.

## Consequences

What changes for callers, tests, ops. What enforces it.

## Update 2026-11-21: topic

Later correction or rollout step.
```

Status values seen: `accepted`, `accepted (stage or sub-batches ...)`, `complete for ... (date)`. Sub-sections use `###`. Reference other ADRs as `ADR 0014 section 11`. Dates are absolute.
